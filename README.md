# Operations Efficiency Analysis | SQL & Power BI

## Project Overview
An end-to-end data analytics project focused on evaluating operational efficiency, identifying process bottlenecks, analysing SLA performance and uncovering operational cost leakage.

## Tools & Technologies
- **MySQL:** Data validation, SQL queries and business analysis.
- **Power BI:** Interactive dashboards, KPI monitoring and data visualisation.

## Dataset
- 5,000 operational request records.
- 18 columns covering departments, process stages, locations, priorities, processing time, SLA performance and operational costs.

## Key Analysis Areas
- Overall operational performance and SLA compliance.
- Department-wise and location-wise efficiency.
- Process bottlenecks and missed SLA targets.
- Overtime and rework cost analysis.
- Error categories and priority-wise performance.

## Dashboard Pages
1. **Executive Overview:** KPIs, request trends and overall efficiency.
2. **Root Cause Analysis:** Departmental performance, process bottlenecks and cost drivers.
3. **Business Recommendations:** Cost leakage, improvement opportunities and actionable recommendations.

## Key Findings
- Analysed 5,000 operational requests.
- Overall SLA compliance: 71.94%.
- Average processing time: 18.40 hours.
- Identified Claims Processing as the lowest-performing department for SLA compliance.
- Identified Process Errors as the highest rework cost category.

## Project Deliverables
- Raw dataset (CSV)
- SQL analysis file
- Interactive Power BI dashboard (PBIX)
- Final project report (DOCX)
- Dashboard screenshots

## Business Recommendations
- Strengthen data validation to reduce rework.
- Improve SLA performance in underperforming departments.
- Optimise workload allocation to control overtime.
- Monitor operational KPIs regularly using Power BI.
